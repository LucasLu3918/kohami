# KOHAMI 領域術語表

版本 v0.1｜2026-10-13｜現行產品語言

## 商務與展示邊界

| 術語 | 定義與邊界 |
| --- | --- |
| 商品 Product | 一個服裝款式的商品資訊；同款可含多個顏色／尺寸 SKU。 |
| 商品規格 SKU | 真實販售的顏色／尺寸組合，具唯一識別。商品款數不等於 SKU 數。 |
| 可銷售庫存 Sellable Stock | 可用於新交易承諾的庫存；與已保留數量分開。具體演算法待庫存規格。 |
| 庫存保留 Reservation | 為交易流程暫時保留的數量；期限、釋放與付款競爭需另訂。 |
| 訂單價格快照 Price Snapshot | 保存交易成立時的價格、優惠與費用條件；不以現行商品資料覆寫。 |
| 付款嘗試 Payment Attempt | 一次付款處理的紀錄；不等於訂單，也不代表已收款。 |
| 商品可購買性 Product Availability | 是否滿足販售、庫存及交易條件；換裝圖片成功不能決定它。 |
| 換裝可用性 Fitting Availability | 指定角色／SKU／視角／版本是否能提供合格展示；獨立於庫存。 |

## 固定模特與素材

| 術語 | 定義與邊界 |
| --- | --- |
| 模特換裝參考 Visual Fitting Reference | 使用固定資產展示服裝外觀的正式功能名稱；非本人實拍與合身保證。 |
| 預設角色 Preset Avatar | 商店預先製作並提供顧客選擇的展示模特，不代表顧客本人。 |
| 角色組別 Avatar Family | 具有一致展示識別及身形特徵的基礎角色系列；男女各 A／B。 |
| 身形尺寸設定 Body Size Profile | 某角色尺寸版本的身高及圍度等參考資料；不是會員身體檔案。 |
| 角色尺寸變體 Avatar Size Variant | 相同角色在不同支援參考尺寸下的版本；外觀識別保持一致。 |
| 服裝尺寸 Garment Size | SKU 真實販售尺碼及衣服量測，不能用名稱相同判斷角色合身。 |
| 角色介紹展示 Avatar Introduction | 尚未選定身形尺寸前的介紹圖；尚未進入實際換裝。 |
| 基礎服裝 Base Garment | 角色預設穿著的適當中性底層服飾，用於公開展示。 |
| 視角 View Direction | 正面、右側面、背面三個固定方向；不包含 360° 自由旋轉。 |
| 角色／服裝三視圖 View Set | 同一角色尺寸或服裝規格在三個約定方向的一致資產集合。 |
| 換裝模組 Fitting Module | 可重用角色、服裝及必要對齊資訊的視覺構件。 |
| 相容性矩陣 Compatibility Matrix | 經審核的角色身形 × SKU × 視角 × 素材版本組合規則。 |
| 可換裝 SKU Fitting-Ready SKU | 已具合格素材且至少支援公告組合的商務規格，不代表全身形可用。 |
| 素材版本 Asset Revision | 可追溯的角色或服裝資產修訂，收藏須保留必要關聯。 |

## 瀏覽、收藏與維護

| 術語 | 定義與邊界 |
| --- | --- |
| 換裝瀏覽階段 Fitting Session | 當前瀏覽期間的角色、尺寸、SKU 與視角操作。 |
| 換裝選擇資料 Fitting Selection Data | 顧客的展示選擇，不得據此推斷真實性別、身體或健康資料。 |
| 穿搭組合 Outfit Configuration | 角色、角色尺寸、服裝 SKU、視角及必要版本所形成的設定。 |
| 已收藏穿搭 Saved Outfit | 會員明確保存至帳號的組合；不等於生成圖片或訪客暫存。 |
| 明確收藏 Explicit Outfit Save | 使用者主動保存指定組合的行為；登入本身不構成收藏。 |
| 穿搭參考匯出 Outfit Reference Export | 主動下載具授權且標示模特示意性質的展示截圖。 |
| 換裝停用 Fitting Suspension | 停止問題模組或組合的展示；不必下架正常販售商品。 |
| 換裝備援展示 Fitting Fallback | 換裝無法使用時改提供真實照片與尺寸資料，維持購物流程。 |

## 共用的用語規則

「可販售」、「有庫存」、「可換裝」分開表達；「角色身形」、「服裝尺碼」、「顧客本人尺寸」分開表達；「暫存選擇」、「帳號收藏」、「下載截圖」分開表達。技術格式與演算法不作為本術語表的領域定義。

## 儲值與履約規劃用語（未來階段提案）

| 術語 | 定義與邊界 |
| --- | --- |
| 會員儲值餘額 Member Stored Balance | 僅供已登入會員支付 KOHAMI 商品的內部餘額顯示名稱；不推定為法律上的電子支付帳戶或免除預付交易義務。 |
| 實付儲值 Paid Stored Balance | 已由可信入金證據確認、記在會員帳本的餘額；不能因付款返回頁或管理員改資料而增加。 |
| 贈送購物金 Promotional Credit | 活動或服務補償產生的非實付餘額；與實付儲值分帳，期限、使用優先序及退款處置另需決策。 |
| 錢包帳本 Wallet Ledger | 記錄會員餘額入帳、扣抵、退款及更正的不可變分錄；畫面餘額是可重建投影，不可任意覆寫。 |
| 人工履約紀錄 Manual Fulfillment Record | 有權限後台人員輸入的交運／配送狀態及佐證；描述店家記錄，不等於承運商即時回報。 |
| 退貨案件 Return Case | 追蹤申請、受理、寄回、收件與檢查；不等於退款或商品可再售。 |
| 部分退款 Partial Refund | 已退金額小於可退總額的退款結果；與訂單完成、退貨結案分別顯示。 |

## 現階段模擬服務與售後用語

| 術語 | 定義與邊界 |
| --- | --- |
| 模擬服務 Mock Adapter | 受控後端提供外部結果情境；應用仍執行自己的授權、交易與資料流程，不代表真實服務商確認。 |
| 退款 Refund | 原付款關聯的獨立操作；本階段僅模擬，完成不等於實際資金入帳，不自動回補退回商品庫存。 |
| 配送 Shipment | 訂單的履約與配送紀錄；本階段只進行明示模擬的受控狀態轉移。 |
| 退貨 Return／驗收 Inspection | 退回案件與檢查結果分開；退回不等於可再販售，退款不取代驗收。 |
| 模擬交易憑證 Demo Receipt | 合成交易與退款調整的可追溯示意記錄，無稅務效力，不是有效統一發票。 |

完整目前行為與狀態见 [mock 政策](../../../proposals/kohami/04-demo-commerce-policy.md)；這些是現行文件契約，並非已實作結果。

會員儲值與人工履約是[後續規劃提案](../commerce/WALLET_SETTLEMENT_SHIPPING_PLAN.md)，不得回填或改稱目前 mock 行為已是真實收款／物流。

## 工程階段與契約範圍

| 用語／舊代號 | 明確意義 | 邊界 |
| --- | --- | --- |
| 技術與交易基線（Foundation） | 本機 SQL、身份、SSR、交易、worker 與復原的最小驗證 | 不是業務模組或完整網站；必要驗收為 Foundation-AC01–11；Foundation-AC12 clean checkout／獨立 handoff 為選配改善 |
| 商品與費用確認（M1） | 商品發布、搜尋、SKU、cart 與 Quote | 對應商品旅程，不是獨立部署單位 |
| 結帳付款與訂單（M2） | 庫存承諾、付款結果與自己的訂單 | mock 與會員餘額各依適用契約 |
| 履約與售後（M3） | 配送、退貨驗收、退款、憑證及對帳 | 各狀態分開，退款不直接代表入庫 |
| 本機驗收交付（M4） | 核心完整旅程、品質、故障與復原、可重建交付 | 不代表正式營運或換裝啟用 |
| core34 | 已批准本機技術基線的 34 個 HTTP 操作 | 以批准範圍與 runtime 契約為準 |
| core95／Phase2_36 | 整合候選的 97 個核心及 36 個 Phase 2 HTTP 操作 | 合計 131；操作數不代表完成度或全部批准 |
| canonical candidate | 統一來源後可供審閱的契約候選 | 有檔案、可重現、已採子集與 runtime 驗證是不同狀態 |

新文件與工作包優先使用用途名稱；既有代號保留供驗收、票券與歷史決策追溯。
