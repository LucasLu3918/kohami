## 1. 企劃摘要

建立以台灣為初期市場的單一品牌 B2C 日系服飾電商，提供商品瀏覽、會員、結帳、付款、配送、售後與營運後台。以手機優先、繁體中文／日文／英文內容及柔和日常的品牌體驗，服務主要為 18–35 歲女性的行銷客群，同時讓其他合法購物者自由使用。

差異化功能為「模特換裝參考」：使用事先準備的角色及服裝資產，切換正面、右側面、背面。首版不使用 AI、不收集本人照片、不建立顧客本人形象，不承諾真實合身或布料物理模擬。

規劃採分期交付，先完成能獨立營運的核心商店，再於素材品質及效能達標後開放換裝。功能定位與既有需求相容；固定換裝屬有條件適合，前提是素材授權、跨身形對齊品質及成本驗證通過。

### 1.1 目標與成功條件

- 讓顧客從真實商品資訊完成可信交易，避免重複收款、超賣及不明付款結果。
- 讓換裝成為理解外觀的輔助工具，失敗時仍能查看商品照片、尺寸表與購物。
- 讓營運人員依授權管理商品、庫存、訂單、素材及售後，關鍵行為可追溯。
- 以可量測的效能、可用性與復原目標評估上線條件；轉換率、營收與回購率的正式目標待營運基準建立後決定。

### 3.3 核心購物旅程

顧客瀏覽商品 → 選擇真實顏色與尺寸 → 查閱照片及量測 → 加入購物車 → 確認價格、庫存、配送與費用 → 付款 → 接收可信付款結果 → 配送與售後。

換裝可在商品探索過程使用，但不代替尺碼表與交易驗證。付款結果未知時顯示待確認並導向對帳；不能僅因前台逾時就宣稱付款失敗。

### 3.4 模特換裝旅程

初次展示女性角色 A 的正面介紹圖 → 顧客明確選擇角色身形尺寸 → 選擇商品 SKU → 檢查相容性 → 切換正面／右側面／背面 → 查看真實商品與購買狀態 → 主動下載示意圖或登入後保存穿搭。

瀏覽期間保留角色、身形及視角；登入不自動保存所有嘗試。缺貨商品可繼續展示有效換裝，購買狀態須明示。素材載入失敗、組合不支援或被停用時，提供原因與真實照片／尺寸表入口。

### 3.5 UX 與可及性設計工作

手機版優先安排選擇、查看與購買操作，避免換裝圖片阻塞結帳。後續須設計鍵盤操作、控制項名稱、焦點、圖片替代說明及錯誤提示；詳細可及性標準與測試裝置矩陣待品質規格定義。

## 5. 商務規則與資料生命週期

### 5.1 必須維持的不變條件

同一庫存不得重複承諾；結帳重送不得產生重複有效交易；金流結果未知不得直接宣稱失敗；已付款訂單歷史條件不得覆寫；退款不得無故超出依法應退金額。

取消或庫存保留到期後才收到付款成功，須進入對帳與異常補償，不能直接恢復訂單而造成超賣。交易金額以 TWD 精確計算，折扣、費用及退款分攤須可重現。詳細折扣疊加、退款費用與保留期限尚須補齊原始規則及供應商限制。

## 6. 模特換裝與素材規格

### 6.1 角色與服裝

男女各兩組不同身體比例的成年標準模特，採半寫實日系型錄插畫與適當中性基礎服裝。同一角色不同尺寸及視角保持外觀識別一致。公開身高、胸圍、腰圍、臀圍及必要肩寬等參考值，但不把它們當成顧客本人資料。

角色尺寸依真實商品與可完成素材決定，優先評估 S／M／L／XL；不是承諾每一尺寸及商品組合均支援。四組角色及公告支援尺寸需具三視圖；不限制顧客選擇角色性別分類，但跨身形組合須經驗收。

服裝素材來自真實攝影、合法授權供應商或人工製作且核對的圖像。網站不猜測看不到的背面。顏色、尺寸、三視圖均須正確，經證明可安全共用的素材才允許重用。首批約 20 個 SKU，優先上衣、針織；商品款數、商務 SKU 數與素材組合數分開估算。

### 6.2 素材與相容性概念契約

| 資料概念 | 必要資訊／責任 |
| --- | --- |
| 角色組別 | 角色識別、成年標準模特分類、外觀與身形差異 |
| 角色尺寸 | 所屬角色、參考量測、支援狀態與三視圖版本 |
| 服裝資產 | 真實 SKU、視角、顏色尺寸、來源、授權及版本 |
| 對齊資訊 | 姿態、比例、錨點／遮擋等必要組合資料；具體格式待設計 |
| 相容性 | 角色身形 × SKU × 視角 × 素材版本的驗收結果 |
| 已收藏穿搭 | 角色、角色尺寸、SKU、視角與素材版本關聯 |

收藏暫定最多 20 組；保存設定優先於保存獨立圖片。素材失效時揭露無法重現，或提供可用替代，不默默把錯誤的新圖冒充舊收藏。匯出須在相應授權範圍內，標示為品牌模特示意。

### 6.3 製作與審核作業

確認素材來源與授權 → 製作角色／服裝三視圖 → 建立對齊與版本資訊 → 驗收顏色、比例、袖子、衣長、頭髮遮擋及身體輪廓 → 公告合格組合 → 啟用 → 持續處理更版、授權與停用。

素材準備、審核與維護需要人力和預算。採 Canvas、透明圖層、遮罩或其他技術仍屬工程細節，須以合格資產實證決定。

### 8.2 安全與資料原則

規劃維持 MFA、細粒度權限、秘密掃描、可信金流驗證、日誌去識別化、備份及可追溯發布。公開商品／角色素材與會員收藏資訊分開管理；角色選擇不得被推斷為真實性別、體重、體型或健康資料，也不預設用於推測式廣告。

網站不收集個人照片，但帳號、訂單、配送及收藏仍含個人資料。保存期限、刪除、營運存取與第三方處理責任須於資料規格及正式政策中明訂。授權撤銷的素材不能因快取而繼續公開。

## 9. 成本、人力與風險

### 9.1 預算基準

原訪談保留核心網站技術預算 NT$8,000／月，屬暫定規劃上限，尚未證明足以達成可靠性與復原要求。原 NT$12,000／月 AI 推論用途停用，不自動轉撥為素材或其他支出。

固定換裝另估一次性角色製作、各尺寸／視角服裝加工、相容性審核，以及持續素材維護、儲存與流量。電商開發、人力、商品採購、營運、供應商服務費與其他商業成本的正式金額尚待報價；上述技術數值不代表整體專案預算。

### 9.2 工作量估算方法

角色資產量依「4 組角色 × 實際支援尺寸 × 3 視角」估算。服裝工作量依「實際 SKU × 必要角色身形適配 × 3 視角」檢查，允許已證明安全的素材共用，不把每個組合視為一定要獨立作畫。

後續工作需涵蓋產品／設計、前後台工程、素材製作、營運、品質與安全審查。角色與人數可兼任，但工時、人力及交付日期目前未定。

### 9.3 主要風險與處理

| 風險 | 可能影響 | 應取得的證據／處理 |
| --- | --- | --- |
| 品牌權利或網域不符 | 更名與品牌重做 | 正式查核後由使用者選定 |
| 跨身形素材不自然 | 顧客誤解、素材量與成本上升 | 樣本品質驗收；不合格組合不開放 |
| 圖片流量／手機負擔 | 首次載入慢、記憶體不足 | 真實裝置與網路量測、降級方案 |
| 付款與庫存競爭 | 超賣、重複付款或售後成本 | 異常場景與冪等／補償驗證 |
| 預算不足 | 可靠性或範圍無法同時滿足 | 實測報價後調整範圍，提交使用者決定 |
| 素材授權到期／更版 | 公開展示或收藏失效 | 授權與版本追溯、獨立停用、快取撤除 |
| 早期決策來源不完整 | 詳規遺漏交易或營運政策 | 完整訪談補齊後再做實作規格審查 |
