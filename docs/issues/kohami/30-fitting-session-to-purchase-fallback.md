# 30: 跨頁比較並回到真實商品購買

**What to build:** Fitting Session 保留角色、身形與視角；展示連結權威 SKU／售價／庫存，缺貨不可購買，素材失敗仍可完成正常購物。

**Blocked by:** 13：完成付款並顯示可信結果；29：從素材審核到首次三視圖換裝

**Status:** ready-for-agent

- [ ] 跨商品頁與換裝頁保留當前角色、Body Size Profile 及視角，真實 SKU 選擇按相容性處理，不暗中代選訂單尺碼。
- [ ] 展示及購買入口引用商務權威 SKU、價格、庫存；缺貨 SKU 可保留合格換裝但不能完成有效購買。
- [ ] 注入素材讀取失敗或不支援組合後提供 Fitting Fallback，顧客仍可查看照片、尺寸表並完成正常沙盒購物。
- [ ] 訪客選擇僅作當前瀏覽用途，不因登入建立收藏，也不推斷本人性別、身體或健康特徵。
- [ ] 驗證跨頁成功、過期商務資料、缺貨拒絕與失敗備援，圖片成功不得當成交易可購買性證據。
