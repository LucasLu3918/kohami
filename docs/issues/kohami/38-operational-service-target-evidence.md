# 38: 以實際營運紀錄驗證服務目標

**What to build:** 取得營運啟用批准後，追蹤月可用性、出貨／客服時效、每日對帳、季度復原及實際成本；資料不足不宣稱達標，也不自動擴充 Phase 3／4。

**Blocked by:** 26：核心商店獨立交付與啟用審查；[production-launch/01：正式啟用前驗收](../production-launch/01-go-live-readiness.md)及實際正式啟用

**Status:** ready-for-agent

- [ ] 僅在取得獨立營運啟用批准並完成啟用後收集已確認用途的最小必要紀錄；本票完成前置工作不等於已正式營運。
- [ ] 按確認監測口徑與完整量測期評估核心商務每月 99.9% 規劃目標，樣本／期間不足保持未驗證。
- [ ] 依營業日及例外核對付款確認後約 2–3 營業日出貨、一般客服兩營業日與高風險付款一營業日首次回應目標，附實際紀錄與限制。
- [ ] 核對每日對帳、重大警示及初期至少每季復原演練的實際執行情形；未執行項目不填 PASS。
- [ ] 比較實際服務、人力與維護成本及估算，提出有證據的改善建議，不自動建立 Lookbook、轉換分析、國際擴充或其他 Phase 3／4 功能。
- [ ] 營運證據包含日期、範圍、版本、方法、結果、責任及限制，遵守資料保存政策，不長期保存原始提示、工具輸出或未授權個人資料。
