# 07: 查核品牌、商家與商品來源

**What to build:** 整理正式品牌／網域、營業資格、商品來源及標示的可審查證據，讓正式商店不建立在未驗證商業條件上。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 於授權查核範圍內記錄品牌／網域權利與可用性、商家收款／發票資格、商品標示及正式審查需求，附日期、來源與限制。
- [ ] 核對首批商品合法來源、真實照片、量測、供應商報價與毛利模型，分開記錄商品款數與 SKU 數。
- [ ] 正式品牌、網域、商品數量及售價由必要決策確認；KOHAMI 與既有參考價格保持候選／暫定狀態直到確認。
- [ ] 缺少資格、權利、報價或專業審查者列為未通過，不因文件整理而採購、註冊網域或給出正式合規結論。

### 2026-10-22 公開規範與查核入口盤點

- **品牌／商標：** 經濟部智慧財產局的[商標檢索系統](https://cloud.tipo.gov.tw/S282/S282WV1/)提供文字近似、圖形近似等查詢；其說明指出資料涵蓋申請中、已註冊及被核駁案件。正式檢索仍需先確定品牌圖樣、指定商品／服務類別並評估近似案件。本輪沒有提交「KOHAMI」或特定類別查詢，不能據此認定可註冊或無權利衝突；KOHAMI 維持候選品牌。
- **公司名稱：** 經濟部[公司名稱暨所營事業預查輔助查詢](https://serv.gcis.nat.gov.tw/pub/cmpy/nameSearchListAction.do)要求以公司名稱開頭的中文字查詢，結果只作輔助篩選，實際可用名稱仍以正式申請核准為準。尚無正式中文名稱或已決定的營業主體，因此沒有可執行的名稱查詢或核准結論。
- **網域：** [TWNIC 註冊系統](https://rs.twnic.tw/)提供 WHOIS 查詢入口；一般頂級網域可用 [ICANN Lookup](https://lookup.icann.org/)查詢。專案尚未決定頂級網域或候選完整網域，本輪未查詢特定網域；可用性與所有權均未知，也未註冊任何網域。
- **稅籍與營業稅：** 財政部[境內網路交易應注意事項](https://www.etax.nat.gov.tw/etwmain/tax-info/network-transaction-taxtation-area/seller/notice)頁面更新日為 2026-10-22；頁面說明自 2025-01-01 起，全部透過網路銷售者的月銷售額起徵點為貨物新臺幣 10 萬元、勞務 5 萬元，並提示免辦稅籍登記者仍有營利所得申報事項。是否適用須依實際主體、交易模式及銷售額確認，不能由此替本專案判定資格或稅務處理。
- **信用卡與電子發票：** 金管會《[信用卡業務機構管理辦法](https://law.fsc.gov.tw/LawContent.aspx?id=FL006433)》將特約商店定義為與收單機構簽約並接受信用卡付款的商店；財政部[電子發票整合服務平台營業人申請頁](https://wwwtest.einvoice.nat.gov.tw/accounts/signup/b)說明平台供境內營業人存放及交換電子發票。專案沒有營業主體、收單契約、平台帳號／憑證、字軌或出票資格證據；不得視為已可收款或開立正式發票。
- **服飾標示：** 標檢局[服飾標示基準](https://www.bsmi.gov.tw/wSite/laws/review.jsp?lawId=502880825f6c6ec0015f6cb95eb51111)列有適用服飾種類及標示事項，包含製造／委製／分裝或進口商資訊、原產地、纖維或填充物成分、尺寸及洗燙方式；部分資訊的標示位置與方式另有要求。具體適用仍須依商品種類、材質、產地與包裝核對。本專案尚無首批 SKU、材質、產地或供應商資料，不能逐款判定標示或檢驗要求。
- **網路消費資訊：** [消費者保護法第 18、19 條](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=J0170001)涉及通訊交易提供賣方、商品、價格、付款、交付、解除權及申訴資訊，並規定通訊交易原則上的七日解除權及法定例外。後續須依實際賣方、商品與交易條件審查，不以本段代替法律意見。

**尚缺的結案輸入：** 正式品牌與圖樣、指定商品／服務類別、中文營業名稱、營業主體及適用法域、候選網域、收款／發票資格，以及首批商品清單（商品款數與 SKU 數）、合法來源、真實照片、尺寸量測、供應商報價與成本。以上未確認前，本票四項驗收維持未勾選；不得採購、註冊、上架正式商品或宣稱權利／法遵已通過。
