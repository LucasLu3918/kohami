# 23: 最小化報表與資料生命週期

**What to build:** Analyst 只取得授權且最小化的營運資訊；保存、刪除及敏感存取依政策執行並可稽核。

**Blocked by:** 20：受控退款與財務核對

**Status:** ready-for-agent

- [ ] Analyst 從後台取得已授權的最小營運報表，不能藉查詢或匯出取得超出必要用途的個人／交易資料。
