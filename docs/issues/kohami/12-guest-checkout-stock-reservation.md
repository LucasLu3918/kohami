# 12: 訪客結帳與可靠庫存承諾

**What to build:** 結帳重新驗證價格及庫存，建立可追蹤的待付款訂單；並行與重送不超賣、不重複建立有效交易，保留交易條件。

**Blocked by:** 11：確認 SKU、購物車與完整費用

**Status:** ready-for-agent

- [ ] 訪客無須註冊即可確認聯絡／配送資料與交易條件，服務端重新核對權威 SKU、價格、費用及可承諾庫存。
