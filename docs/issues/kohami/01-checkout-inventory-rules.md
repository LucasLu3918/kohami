# 01: 確認結帳與庫存交易規則

**What to build:** 確定金額精度、優惠與費用分攤、庫存保留、重送、取消及晚到付款的處理，讓顧客與營運人員在交易競爭或異常時得到一致結果。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Work status:** resolved（政策規格與確認；不是產品驗收）

- [x] 依現行來源列出 TWD 精度、捨入、折扣疊加、費用分攤、Reservation 期限及釋放規則；缺少來源者明列待決，不填造政策。
- [x] 以可審閱的狀態與情境表描述結帳重送、同 SKU 並行、取消、前台逾時及保留到期後付款成功，列出操作者、可信輸入、外部結果與補償。
- [x] 每個情境維持不超賣、不建立重複有效交易、未知付款不直接宣稱失敗、歷史交易條件不被改價覆寫。
- [x] 取得重大業務規則的明確確認並記錄來源；未解決條件保留為阻擋，附瀏覽器旅程及必要交易邊界的驗收方式。
