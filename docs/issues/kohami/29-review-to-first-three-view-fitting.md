# 29: 從素材審核到首次三視圖換裝

**What to build:** 後台審核一組完整相容組合；訪客先看女性 A 正面介紹，明選身形與服裝尺寸後換裝，不支援組合提供實拍入口。

**Blocked by:** 09：維護可銷售庫存與缺貨狀態；28：確認換裝、收藏與匯出契約

**Status:** ready-for-agent

- [ ] 從授權後台登記素材來源、權利、View Set、Asset Revision 與相容性審核，到訪客使用至少一組合格身形／SKU 的三視圖，完整旅程可驗證。
- [ ] 全新瀏覽先為女性 A 正面 Avatar Introduction，未明選 Body Size Profile 前不暗中啟用角色尺寸。
- [ ] 角色身形與真實服裝尺寸分開選擇，公布參考量測並提示不保證本人合身；一次更換一件，正常使用免費且不限生成額度。
- [ ] 正面、右側面、背面有明確控制；未審核、失效、授權不足或不相容組合不展示錯誤換裝，提供原因及照片／尺寸表。
- [ ] 驗證訪客成功、拒絕與載入失敗，後台越權審核被拒絕；不提供 360°、本人照片或 AI。
