# 16: 會員購物與受保護的訂單紀錄

**What to build:** 會員依確認方式登入、結帳及查閱自己的訂單；訪客仍能安全查詢交易，不能存取他人資料。

**Blocked by:** 13：完成付款並顯示可信結果

**Status:** ready-for-agent

- [ ] 會員以確認方式登入、使用購物車結帳並從會員中心查看自己的可信訂單與歷史條件。
- [ ] 訪客仍能無註冊結帳及依身份政策查詢自己的交易，不把建立會員當成購物前提。
- [ ] 登入／登出、過期身份與跨帳號存取維持資料隔離；嘗試存取他人訂單被拒絕。
- [ ] 覆蓋成功、身份驗證失敗與服務錯誤，帳號／通知資料處理遵守保存與用途政策。
