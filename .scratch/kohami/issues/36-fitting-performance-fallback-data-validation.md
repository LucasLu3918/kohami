# 36: 換裝效能、備援與資料邊界驗收

**What to build:** 分開量測首次載入與就緒切換，驗證手機效能、可及性及失敗降級；確認無 AI、本人照片、身體特徵推斷或永久公開穿搭網址。

**Blocked by:** 32：會員明確收藏與版本失效提示；33：訪客與會員下載授權示意截圖；35：首批 SKU 相容性與換裝資格公告

**Status:** ready-for-agent

- [ ] 依正式裝置／網路矩陣及事件定義分開量測首次載入、傳輸量、記憶體與素材就緒後商品／視角切換 P75 ≤ 1 秒，附樣本及限制。
- [ ] 以訪客／會員旅程驗證首次介紹、獨立尺寸選擇、三視角、跨頁、收藏、匯出及手機／鍵盤／輔助技術操作。
