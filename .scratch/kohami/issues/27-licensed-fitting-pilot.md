# 27: 合法素材的最小換裝實證

**What to build:** 以具測試權利的角色／SKU 完成固定三視圖樣本，人工核對外觀、遮擋與量測，實測手機負擔及製作成本。

**Blocked by:** 08：從後台上架到顧客查看商品

**Status:** ready-for-agent

- [ ] 在取得所需素材使用／製作及支出授權後，以至少一組角色身形與真實 SKU 示範正面、右側面、背面，來源非 AI 且可追溯。
- [ ] 人工審查顏色、尺寸、角色識別、量測、比例、袖子、衣長及遮擋，不猜測不可見背面，不以圖片成功載入取代品質或權利證據。
- [ ] 在實際裝置記錄首次載入、素材就緒後切換、傳輸量與記憶體，說明條件、樣本及限制。
- [ ] 估算角色／服裝加工、審核、維護與流量成本；不合格時提出有證據的範圍／方法建議，不靜默改變四組或三視圖方向。
- [ ] 實證不建立本人照片、AI 呼叫、GPU 推論、生成額度或正式公開啟用。
