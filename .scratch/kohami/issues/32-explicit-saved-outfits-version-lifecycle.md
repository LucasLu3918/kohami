# 32: 會員明確收藏與版本失效提示

**What to build:** 登入不自動收藏；主動保存包含必要版本的設定，僅本人可存取，版本失效清楚揭露，不靜默換成新圖。

**Blocked by:** 16：會員購物與受保護的訂單紀錄；31：獨立停用、授權撤銷與快取撤除

**Status:** ready-for-agent

- [ ] 訪客登入後只有 Explicit Outfit Save 才建立 Saved Outfit，會員中心可查閱自己明確保存的設定。
- [ ] 收藏保存角色、Body Size Profile、SKU、視角及必要 Asset Revision 關聯，不把暫存或登入當成收藏。
- [ ] 素材更版、停用或權利失效時明示無法重現或清楚標示可用替代，不以新圖冒充原收藏。
- [ ] 跨帳號讀取／修改被拒絕，收藏依保存／刪除政策處理，不產生永久公開穿搭配置頁。
- [ ] 驗證保存、讀取、身份失效與版本失效；數量上限只有確認後才加入邊界案例，未確認不寫死 20 組。
